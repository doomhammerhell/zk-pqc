# Security Policy

## Supported Versions
Given the critical nature of Layer 0 Cryptographic Infrastructure, only the `main` branch and explicitly tagged stable releases undergo formal security evaluation and receive immediate vulnerability patches.

## Reporting a Vulnerability
Do **NOT** open a public issue for cryptographic or structural vulnerabilities.
Please email `security@example.com` (replace with actual inbox in deployment) with a detailed description of the exploit, proof of concept, and trace extraction logs. 

All verified post-quantum algorithmic or bounding flaws will be addressed within 48 hours according to our zero-tolerance policy.
